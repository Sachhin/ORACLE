# Independent ORACLE expert-review invitation template

**Status:** template only. No reviewer has been recruited and no scores exist.

## Invitation

Subject: Request for independent blinded evaluation of an AI-assisted scientific research system

Hello,

I am seeking two independent reviewers with relevant expertise in biology, ageing research, bioinformatics, or scientific methods to evaluate ORACLE, an AI-assisted research system.

The review is a blinded, paired comparison of two answer sets generated from the same frozen scientific questions and source packets. System identities will be hidden and A/B order randomized. Reviewers will independently score evidence fidelity, correctness, treatment of contradictory evidence, methodological rigor, uncertainty calibration, reproducibility, and whether conclusions exceed the available data.

The review does not ask you to endorse ORACLE or validate a biological discovery. It is an evaluation of research-output quality. The packet will contain source references, a scoring rubric, and a return template. Please disclose relevant expertise and any conflicts of interest before accepting.

Would you be willing to review a bounded packet and return the completed score file by an agreed date? No confidential or identifiable patient information is required.

Thank you.

## Maintainer checklist

- [ ] Recruit at least two independent domain experts.
- [ ] Record reviewer identity, expertise, and conflict-of-interest declaration outside blinded packets.
- [ ] Freeze the paired answer corpus, source packets, prompt/model versions, and SHA-256 hashes.
- [ ] Generate separate randomized A/B packets and keep unblinding keys private.
- [ ] Send only each reviewer their assigned packet and score template.
- [ ] Freeze returned score files; validate completeness and reviewer identity.
- [ ] Adjudicate disagreements before unblinding.
- [ ] Publish anonymized aggregate results, uncertainty, reviewer agreement, and limitations.

Never create placeholder reviewer identities, scores, or approval records to satisfy the release gate.
